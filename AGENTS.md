# Agent Instructions

This repo is built by a multi-session Claude Code team (team lead, researcher,
developer — possibly across different worktrees). These rules apply no matter
which session you are.

- Follow `CONTRIBUTING.md` for branching/commit/PR workflow and safety rules.
- Never read, write, or delete anything outside this repo directory.
- Be concise: brief status updates, no padding in docs or READMEs, don't
  re-read files already in your context. Token usage matters here.
- No secrets committed — read API keys from env / gitignored files only.
